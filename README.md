# CC Trace Mobile

在手机上查看 Codex 与 Claude Code 的订阅额度。

| 仓库 | 地址 | 说明 |
|---|---|---|
| 桌面端 CC Trace | https://github.com/nanvon/cc-trace | macOS 菜单栏 / Windows 托盘应用 |
| 移动端（本仓库） | https://github.com/nanvon/cc-trace-mobile | iOS / Android 应用 |

两个仓库、两个应用，各自独立。移动端不是桌面端的移植，只共享同一套视觉语言和额度口径。

> ⚠️ **还不能装来日常用。** 功能代码已经写完，但一次真实账号、真机上的完整验证都还没做过，
> 也没有发布任何安装包。现在来这里，请当成一个开发中的项目看待。

## 它解决什么问题

订阅了 Codex 或 Claude Code，想知道额度还剩多少、什么时候重置——但人不在电脑前。

打开这个应用就能看到，不用开电脑、不用登官网翻。

## 你会看到什么

**Codex**

- 当前额度窗口的剩余百分比和重置时间
- 攒下的重置次数（Reset Credits）和最早过期时间，点卡片展开看完整时间明细

**Claude Code**

- 5 小时窗口的剩余百分比和重置时间
- 每周窗口的剩余百分比和重置时间
- 如果你的套餐有模型专项额度（比如 Opus、Fable），会一并列出

数据只读，不多不少：应用不显示账户余额，也不显示对话内容。

**关于「剩余」**：越接近用完，进度条颜色越靠近警示色，一眼能看出该省着点用了。数据取不到时
会明说取不到（比如「重置时间未知」），不会留空让你自己猜。

## 怎么登录

点登录，跳转到 Codex 或 Claude Code 的**官方登录页**完成授权，然后自动跳回应用。

- 登录信息只保存在你这台手机的系统安全存储里（iOS Keychain / Android Keystore）
- 两个服务可以只登一个，之后随时在设置里补另一个
- 退出登录会同时删掉本机保存的凭据和额度缓存

## 隐私

- ❌ 不读取、不上传你的对话内容和代码
- ❌ 不把登录凭据发到任何第三方服务器——本项目**没有**自己的服务器
- ✅ 只向 Codex 和 Claude Code 官方接口请求额度数据
- ✅ 所有数据留在你自己的手机上

## 刷新频率

Provider 对额度接口的限流可能比较严格，所以应用刻意刷得比较克制：

- 打开应用先显示上次缓存的数据，再决定要不要请求
- 下拉可以手动刷新，但太频繁时会直接告诉你「稍后可再刷新」，而不是转半天再报错
- 后台自动刷新间隔可在设置里选 15 / 30 / 60 分钟，默认 30 分钟
- 只在应用处于前台时刷新，不在后台偷跑、不发通知

## 安装

**目前没有可下载的安装包。** 两个平台都需要自己用 Flutter 从源码构建：

```bash
flutter pub get
```

Android 构建见 [Android 正式签名与发布](docs/Android正式签名与发布.md)。

iOS 侧只支持用**免费 Apple ID** 自签安装，每 7 天需要重新签名一次——本项目不打算购买
Apple 开发者账号，所以不会有 App Store 版本，也不会有 TestFlight。

## 已知风险

应用使用官方 CLI 所用的 client ID 和非公开接口来登录、读取额度。Provider 随时可能收紧策略，
届时登录或额度查询会失效。这是这条实现路径本身的代价，无法从技术上消除。
