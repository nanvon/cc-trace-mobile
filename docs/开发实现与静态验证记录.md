## 2. 已实现

### OAuth 与凭据

- Codex：1455 → 1457 端口回退、PKCE / state、系统浏览器、form token 交换。
- Claude Code：41999、PKCE / state、系统浏览器、JSON token 交换且携带 `state`。
- 两端统一覆盖取消、5 分钟超时、非法回调、重复回调和端口占用。
- Android 绑定真实 `CustomTabsService` / `CustomTabsSession`，并显式禁止初始导航链或后续
  重定向把 localhost 交给外部默认处理器。
- Session 绑定或创建失败时，退回锁定同一默认浏览器 package 的普通 Custom Tab，不交给
  ChatGPT / Claude App 或钉钉等通用 URL 处理器。
- localhost 同时监听 `127.0.0.1` 与 `::1`；redirect URI 仍严格保持 Provider 白名单要求的
  `localhost` 字面量。
- Android 收到合法回调后显式恢复 `MainActivity`；成功页另提供
  `cctrace://oauth-finished` 兜底，并通过 `singleTask + onNewIntent` 复用现有 Activity。
  该地址不携带 code、state 或 token，也不决定 OAuth 成功。
- access / refresh / id token 只写入 `flutter_secure_storage`，每个 Provider 一份 JSON。
- iOS 使用 `unlocked_this_device` Keychain；Android 关闭应用备份。
- 普通偏好里放安装标记；检测到新安装时清理可能残留的 Keychain 凭据和额度缓存。
- token 类型与异常文案不输出 token、authorization code 或原始响应。

### Provider 与领域模型

- Codex 通用解析 `primary_window` / `secondary_window`，保留 5 小时窗口恢复的兼容逻辑。
- Claude 同时解析动态 `limits`、旧字段、全模型周窗口和模型级周窗口。
- `unknown` 在解析与缓存层保留，界面不展示。
- Claude 响应中的 `is_active` 不进入领域模型、不写入缓存，也不决定界面文案；任何返回有效
  百分比的支持窗口均显示剩余百分比，`resets_at` 缺失时显示“重置时间未知”。
- Claude 按官方客户端链路请求 `/api/oauth/profile`，读取 `account.uuid`、`account.email`
  与 `organization.organization_type`（套餐名）；profile 失败不阻断额度刷新。
  三者齐备后不再重复请求该接口，缺任意一项则下次取数时补请求。
- Reset Credits 与 Codex usage 并行请求；独立失败只影响该行。
- token 到期前自动 refresh；Codex 和 Claude 使用各自已确认的请求体格式和请求头。

### 缓存与刷新

- 启动先读缓存；只有无缓存或超过设置间隔才请求。
- 身份 key 变化时丢弃旧账号快照，不跨账号合并。
- 新响应缺少 `resets_at` 时，仅按相同 `id + kind` 保留仍在未来的旧重置时间。
- 仅前台 / 回到前台刷新，不实现后台刷新。
- 自动刷新可选 15 / 30 / 60 分钟，默认 30 分钟。
- 手动刷新 60 秒节流；429 与网络 / 协议失败分别退避，手动操作不能绕过。
- 每个 Provider 独立请求、去重、失败和退避；旧快照在失败时保留为 stale。

### 界面

- 默认入口为正式“用量”主屏，不加底部标签栏。
- 逐值沿用原型的 HeroUI 浅 / 深色 token、18px 卡片、38px 百分比和 44 × 44 顶部动作区。
- 2026-07-30 排版修订：主进度条 10px → 9px；`%` 单独降到 18px；额度窗口名改用
  小型大写缩写（`5HOUR` / `WEEKLY` / `ALL` / 模型名大写）；倒计时与时距压成
  `6d2h`、`1h42m`、`1m 前已刷新`；所有数字位启用等宽数位。规则见
  [移动端额度展示要求 §5.1](移动端额度展示要求.md)。
- 卡片首行改为「Provider 名 + 账号 + 套餐」基线对齐单行。原实现用
  `Spacer` + `Flexible` 并列，两者各分走一半剩余宽度，导致空间充足时邮箱仍被省略；
  现在账号是唯一弹性项，套餐留在弹性区之外不会被挤掉。
- 原型 9 种状态均由真实状态机可达：正常、低额度、Max 模型窗口、刷新、退避、旧快照、
  单 Provider 未登录、首次引导、首次加载。
- Codex 与 Claude 卡片按真实数据自然不等高；不造占位窗口。
- Codex 卡片保留折叠摘要，点击后以可中断的无回弹弹簧向下展开，只列出接口实际返回的
  可用 Reset Credit 过期时间；相同时间合并显示，缺失明细明确降级，不额外发请求。
  额度窗口的重置时间不在展开态重复（推翻记录见
  [移动端额度展示要求 §3.2](移动端额度展示要求.md)）。展开没有可见箭头或提示文案，
  无障碍语义仍标注 button / expanded。
- 设置页包含登录 / 重新登录 / 退出、系统 / 浅 / 深主题和前台刷新间隔。
- Q3 验证工具只在 Debug 构建设置页出现，Release 不提供入口。
- Claude 套餐名改从 `/api/oauth/profile` 的 `organization.organization_type` 取得，
  经固定映射表转成 Pro / Max / Team / Enterprise，随 `TokenBundle.plan` 留存；
  表外取值不显示套餐。字段来源与排除过程见
  [移动端额度展示要求 §8.1](移动端额度展示要求.md)。
